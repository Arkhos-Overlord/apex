Higher-Order Functions

In Python, functions are first-class objects. This means you can pass them as arguments to other functions, return them from functions, and assign them to variables. 

def apply_twice(f, x):
    return f(f(x))

def double(x):
    return x * 2

print(apply_twice(double, 5))  # 20

The apply_twice function is a higher-order function — ittakes another function as an argument.
